Objective

The idea is to use make a PCA over political stringency indicators to understand what are the main political stringency “axis” i.e. the main differences among communes in political stringency indicators across France?

Remove outliers

Code 
# remove NAs and remove Corsica
keep <- complete.cases(ind) & dfI$INSEE_REG != 94
indF <- ind[keep, ]
df <- dfI[keep, ]

iqr_var <- apply(indF, 2, sd)
med_var <- apply(indF, 2, mean)
low_th <- med_var - iqr_var * 5
high_th <- med_var + iqr_var * 5

out <- t(t(indF) < low_th | t(indF) > high_th)
# apply(out, 2, sum)
# table(apply(out, 1, any))
rm_outlier <- apply(out, 1, any)
# table(keep)
indF <- indF[!rm_outlier, ]
df <- df[!rm_outlier, ]

shp <- shp[match(df$INSEE_COM, shp$INSEE_COM)]

We decided to remove:

  • municipalities with missing values on the indicators (N=2899)
  • Corsica municipalities (N=360)
  • outliers identified as \(mean ± 5 * sd\) (N = 747)

At the end, we have a table made of 31043 municipalities and 12 variables.
